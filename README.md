# Sales-Performance-Dashboard-Excel-Project
📌 Overview

This project is an interactive Sales Performance Dashboard built using Microsoft Excel. It helps analyze and visualize sales data to track performance, identify trends, and support business decision-making.

🎯 Objectives
Monitor overall sales performance
Identify top-performing products and regions
Track monthly and yearly sales trends
Provide insights using data visualization
🛠️ Tools & Technologies
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers & Filters
Conditional Formatting
📂 Dataset

The dataset includes:

Order ID
Product Name
Category
Region
Sales Amount
Quantity Sold
Order Date
📊 Dashboard Features
📈 Sales Trend Analysis (Monthly/Yearly)
🌍 Region-wise Sales Distribution
🏆 Top Products by Sales
📦 Category-wise Performance
🔍 Interactive Filters using Slicers
🚀 Key Insights
Identified highest revenue-generating regions
Detected seasonal sales trends
Highlighted top-selling products
Improved data-driven decision-making
